# audittoken

Audit HTML/Markdown token fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/audittoken/

## Install / run

```bash
git clone https://github.com/theworker02/audittoken.git
cd audittoken
node src/cli.js
node --test
```
